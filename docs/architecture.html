Breakdance Coach
Architecture

Real-time skeletal keypoint tracking pipeline with DTW-based sequence comparison, keyframe thresholding scorer, and live OpenCV overlay.

MediaPipe DTW Python 3.11 OpenCV NumPy asyncio Docker
Rendering diagram_
Input layer

Webcam feed or sample video. Reference moves stored as .npy sequences + JSON metadata.

Vision & preprocessing

MediaPipe extracts 33 landmarks. Coordinates normalized to hip-center origin and buffered in a 60-frame deque.

Comparison engine

Async DTW aligns user sequence to reference. Embedding lookup via cosine similarity for move recognition.

Scoring engine

Keyframe detector triggers joint-angle checks. Thresholding awards 100 / 40 / 0 pts. Combo multiplier on streaks.

Output layer

OpenCV renders skeleton overlay, per-joint correction hints, and a live score HUD with letter grade.
